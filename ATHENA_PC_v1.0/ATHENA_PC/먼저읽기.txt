아테나 PC 1.0 — 처음 실행하기

1. ZIP 압축을 모두 풉니다.
2. 아테나_실행.cmd를 두 번 클릭합니다.
3. 기본 브라우저에 아테나 장부가 열립니다.

필수: Python 3.10 이상. 별도 pip / npm 설치는 없습니다.
Python이 없으면 실행 파일이 안내를 표시합니다.

먼저 연습하려면 아테나_체험.cmd를 실행하세요.
가상 예시 자료이며 실제 장부와 다른 폴더에 저장됩니다.

실제 장부는 품목 등록 → 거래처 등록 → 판매 등록 순서로 시작합니다.
기록은 PC에 자동 저장됩니다. 종료는 실행 창에서 Ctrl+C입니다.
설정 및 백업에서 자료를 내려받아 USB에도 보관할 수 있습니다.

포함: 재고·입출고 이력, 거래처, 판매, 입금, 미수금, 반품·환불,
거래명세서 인쇄, CSV 내보내기, 자동 백업·복원.

이 버전은 한 PC용입니다. 다른 PC·휴대폰 동시 접속은 지원하지 않습니다.
Windows 실기기·화면 클릭 검수는 미완료이며, 데이터와 HTTP 동작을 검증했습니다.
